Inside the cockpit

What it does

AI Boardroom

Decisions run as isolated multi-perspective debates with critic cross-examination and synthesis, across 55 frameworks from OKR to Pre-Mortem.

OmniRoute cost control

A central switchboard routes every request to local (Ollama, LM Studio) or cloud models. Budgets are checked before dispatch and attributed per model and per task.

Zero-Egress routing

Finance, contract and CRM work stays on local models. Worker containers run in an internal Docker network with no internet route. Fails closed, not open.

Tamper-evident audit log

A SHA-256 hash-chained log records every dispatch, including provider, model and host. Records cannot be altered unnoticed.

Obsidian vault + RAG

Your vault is the knowledge base. Documents and scans are OCR-read, converted to Markdown and indexed into AnythingLLM/Chroma — locally.

Kanban with approval gates

Tasks move through a four-eyes gate: approve, reject with a reason, or escalate on expiry. Email triage, CRM and an ERP suite (alpha) sit on top.

24/7 liveness & self-healing

An async event-loop heartbeat feeds /livez (503 on stall) and Docker auto-restart, backed by an optional external dead-man-switch webhook.

Hardened & traced

SSRF and prompt-injection guards, distributed trace IDs across agent calls, and batched UI rendering for large prompt catalogs.

Telegram, Email & CRM

Triage incoming emails and Telegram messages into Kanban tasks, sync contacts, and manage quotes and contracts in one workspace.

Install

Full stack

Six containers: Archon OS, Hermes Agent, AnythingLLM, Chroma, OmniRoute, Docker socket proxy.

git clone https://github.com/michaelbeatman/ARCHON-OS.git
cd ARCHON-OS
docker compose up -d

Zero-key demo

Read-only showcase without API keys and token cost, for a first look.

ARCHON_DEMO_MODE=true \
docker compose -f docker-compose.demo.yml up --build -d
# open http://localhost:8501

Interactive installers

setup.ps1 for Windows, install.sh for Linux/macOS, or a structured onboarding prompt for your AI coding agent (INSTALL_AGENT.md).

Honest status

Pre-1.0. Interfaces and config keys change between releases. The ERP/CRM module is alpha, multi-user role enforcement is still being hardened, and specialist output is decision support, not licensed advice. Issues and PRs are welcome.
