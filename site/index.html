Archon OS

Self-hosted, MIT-licensed multi-agent workspace built on Hermes Agent. Pre-1.0.

What it does

  • Specialist agent profiles across business domains, each with a defined scope and tool rights
  • Kanban task handling with explicit decision gates: approve, reject with a reason, or escalate on expiry
  • Local model routing (Ollama, LM Studio) with cost attribution per model and per task
  • Obsidian vault as the local knowledge source, no hosted vector database required
  • SHA-256 hash-chained audit log, so a record cannot be altered unnoticed

Run it

git clone https://github.com/michaelbeatman/ARCHON-OS.git
cd ARCHON-OS
docker compose up -d

Read-only demo, no API key and no token cost:

ARCHON_DEMO_MODE=true docker compose -f docker-compose.demo.yml up --build -d

Honest status

Pre-1.0. The ERP and CRM module is alpha, multi-user role enforcement is still being hardened, and interfaces change between releases. Issues are welcome.
