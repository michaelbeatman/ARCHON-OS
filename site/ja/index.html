GDPR準拠・Zero-Egress のマルチエージェントOS。ビジネスのため、そしてあなたのために。

Archon OS は Hermes Agent を GDPR準拠のエージェントOSへと拡張します：8ドメイン・70の専門家プロファイル、フェイルクローズ型ローカル Zero-Egress ルーティング、Atomic BudgetBank によるコスト上限、WebAuthn パスキー承認、構造化された AI Boardroom ディベート、GoBD 対応の SHA-256 監査ログ。あなたの文書、あなたの Obsidian Vault、あなたのモデル。

スクリーンショット

主な機能

AI Boardroom

意思決定は、批判役の反対尋問と統合を伴う独立した多視点ディベートとして実行されます。OKR から Pre-Mortem まで 55 のフレームワークを利用できます。

OmniRoute コスト管理

中央のスイッチボードがすべてのリクエストをローカル（Ollama、LM Studio）またはクラウドモデルへ振り分けます。予算は送信前に確認され、モデル単位・タスク単位で割り当てられます。

Zero-Egress & GDPR

財務・人事・契約・CRM データは、インターネット経路のない隔離 Docker ネットワーク内のローカルモデルに留まります。フェイルクローズにより、GDPR の厳格なデータ residency を保証します。

監査ログ、EU AI Act & GoBD

SHA-256 ハッシュチェーンログがすべてのディスパッチ（プロバイダー、モデル、ホスト）を改ざん検知可能に記録し、EU AI Act リスク登録簿とワンクリックの GoBD 手続き文書エクスポートを備えます。

Obsidian Vault + RAG

Vault がナレッジベースです。文書やスキャンは OCR で読み取られ、Markdown に変換され、AnythingLLM/Chroma へローカルで索引付けされます。

承認ゲート付き Kanban

タスクは四眼ゲートを通過します：承認、理由付き却下、期限切れ時のエスカレーション。その上にメールトリアージ、CRM、ERP スイート（alpha）が載ります。

24/7 生存監視 & 自己修復

非同期イベントループのハートビートが /livez（停止時 503）と Docker 自動再起動を駆動し、任意の外部デッドマン・スイッチ Webhook で補完されます。

強化 & トレース

SSRF とプロンプトインジェクションのガード、エージェント呼び出し間の分散トレース ID、大規模プロンプトカタログ向けのバッチ UI レンダリング。

Telegram、メール & CRM

受信メールや Telegram メッセージを Kanban タスクへトリアージし、連絡先を同期し、見積もりと契約を一つのワークスペースで管理します。

パスキー / WebAuthn HITL

高リスク承認（支払い、予算超過、破壊的操作）には Windows Hello、Touch ID、ハードウェアパスキーによる暗号署名が必要です。モデルは承認を偽造できません。

Atomic BudgetBank & 署名付き Warrant

トークンとコストの予算は実行前にトランザクションで確保されます（BEGIN IMMEDIATE）。特権ツールには期限付き HMAC-SHA256 Warrant が必要です。

クラッシュ安全な Effect-Ledger

外部副作用は、冪等キーと未知状態後の必須リコンシリエーションを備えたトランザクション台帳で追跡され、重複実行を防ぎます。

インストール

フルスタック

6つのコンテナ：Archon OS、Hermes Agent、AnythingLLM、Chroma、OmniRoute、Docker socket proxy。

git clone https://github.com/michaelbeatman/ARCHON-OS.git
cd ARCHON-OS
docker compose up -d

キー不要デモ

API キーもトークンコストも不要の読み取り専用ショーケース。まずはこちらから。

ARCHON_DEMO_MODE=true \
docker compose -f docker-compose.demo.yml up --build -d
# http://localhost:8501 を開く

対話型インストーラー

Windows 用 setup.ps1、Linux/macOS 用 install.sh、または AI コーディングエージェント向けの構造化オンボーディングプロンプト（INSTALL_AGENT.md）。

なぜ Archon OS か？

おもちゃのデモではなく、商業的な説明責任と GDPR 準拠のために設計されています。 コスト上限、データ外部送信、コンプライアンス境界を自作の接着コードに任せるプロンプト連鎖ライブラリと異なり、Archon OS はフェイルクローズ型ローカル Zero-Egress ルーティング、Atomic BudgetBank 予約、WebAuthn パスキー承認、EU AI Act / GoBD 文書化、SHA-256 監査証跡を標準で強制します - 3つの統合 SQLite WAL データベース（ops.db、business.db、memory.db）上で。

よくある質問

Archon OS とは？

Archon OS は Hermes Agent ベースの、MIT ライセンス・セルフホスト型エージェントOSです。8ドメインに70の専門 AI ロールを編成し、実行前の予算確保、ローカル Zero-Egress LLM ルーティング、WebAuthn パスキー承認、SHA-256 ハッシュチェーン監査ログを備えます。

機密データの漏洩をどう防ぎますか？

OmniRoute がフェイルクローズ型 Zero-Egress ポリシーを適用します：財務、契約、CRM、人事、GDPR ワークロードは、インターネット経路のない内部 Docker ネットワーク内のローカルモデル（Ollama または LM Studio）でのみ実行されます。

トークンコスト & 危険な操作はどう管理されますか？

中央の PolicyEngine が送信前に権限を検証し、特権ツールには期限付き署名 Warrant が必要で、BudgetBank が資金を原子的に確保し、高リスク承認には WebAuthn パスキー署名が必要です。

GDPR & EU AI Act に対応していますか？

はい。機密業務ワークロードはフェイルクローズ型 Zero-Egress でサーバー内に留まり、EU AI Act リスク登録簿、改ざん検知可能な SHA-256 監査ログ、ワンクリックの GoBD 手続き文書エクスポートで支えられます。

率直な状況

Pre-1.0。インターフェースや設定キーはリリース間で変わります。ERP/CRM モジュールは alpha、マルチユーザー権限の強制はまだ強化中であり、専門家の出力は意思決定支援であって認可された助言ではありません。Issue と PR を歓迎します。
