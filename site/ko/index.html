GDPR 준수 · Zero-Egress 멀티에이전트 OS. 기업을 위해, 그리고 당신을 위해.

Archon OS는 Hermes Agent를 GDPR 준수 에이전트 운영체제로 확장합니다: 8개 도메인의 70개 전문가 프로필, 페일 클로즈 로컬 Zero-Egress 라우팅, Atomic BudgetBank 비용 상한, WebAuthn 패스키 승인, 구조화된 AI Boardroom 토론, GoBD 대응 SHA-256 감사 로그. 당신의 문서, 당신의 Obsidian Vault, 당신의 모델.

주요 기능

AI Boardroom

의사결정은 비판 역할의 반대 심문과 종합을 갖춘 독립된 다관점 토론으로 진행되며, OKR부터 Pre-Mortem까지 55개 프레임워크를 활용합니다.

OmniRoute 비용 관리

중앙 스위치보드가 모든 요청을 로컬(Ollama, LM Studio) 또는 클라우드 모델로 라우팅합니다. 예산은 디스패치 전에 검사되고 모델별·작업별로 배분됩니다.

Zero-Egress & GDPR

재무, 인사, 계약, CRM 데이터는 인터넷 경로가 없는 격리 Docker 네트워크의 로컬 모델에 머뭅니다. 페일 클로즈로 엄격한 GDPR 데이터 거주지를 보장합니다.

감사 로그, EU AI Act & GoBD

SHA-256 해시 체인 로그가 모든 디스패치(공급자, 모델, 호스트)를 위변조 탐지 가능하게 기록하며, EU AI Act 위험 등록부와 원클릭 GoBD 절차 문서 내보내기를 제공합니다.

Obsidian Vault + RAG

Vault가 지식 베이스입니다. 문서와 스캔본은 OCR로 읽어 Markdown으로 변환한 뒤 AnythingLLM/Chroma에 로컬로 색인됩니다.

승인 게이트가 있는 칸반

작업은 4-아이즈 게이트를 통과합니다: 승인, 사유와 함께 거부, 만료 시 에스컬레이션. 그 위에 이메일 트리아지, CRM, ERP 스위트(alpha)가 있습니다.

24/7 상태 감시 & 자가 복구

비동기 이벤트 루프 하트비트가 /livez(정지 시 503)와 Docker 자동 재시작을 구동하며, 선택적 외부 데드맨 스위치 웹훅이 보완합니다.

강화 & 추적

SSRF 및 프롬프트 인젝션 가드, 에이전트 호출 전반의 분산 trace ID, 대형 프롬프트 카탈로그를 위한 배치 UI 렌더링.

Telegram, 이메일 & CRM

수신 이메일과 Telegram 메시지를 칸반 작업으로 분류하고, 연락처를 동기화하며, 견적과 계약을 하나의 워크스페이스에서 관리합니다.

패스키 / WebAuthn HITL

고위험 승인(결제, 예산 초과, 파괴적 작업)은 Windows Hello, Touch ID 또는 하드웨어 패스키의 암호화 서명을 요구합니다. 모델은 승인을 위조할 수 없습니다.

Atomic BudgetBank & 서명된 Warrant

토큰 및 비용 예산은 실행 전에 트랜잭션으로 예약됩니다(BEGIN IMMEDIATE). 권한 있는 도구는 시간 제한 HMAC-SHA256 Warrant가 필요합니다.

충돌 안전 Effect-Ledger

외부 부작용은 멱등성 키와 알 수 없는 상태 이후의 필수 재조정을 갖춘 트랜잭션 원장에서 추적되어 중복 실행을 막습니다.

설치

전체 스택

6개 컨테이너: Archon OS, Hermes Agent, AnythingLLM, Chroma, OmniRoute, Docker socket proxy.

git clone https://github.com/michaelbeatman/ARCHON-OS.git
cd ARCHON-OS
docker compose up -d

키 없는 데모

API 키와 토큰 비용 없이 살펴볼 수 있는 읽기 전용 쇼케이스.

ARCHON_DEMO_MODE=true \
docker compose -f docker-compose.demo.yml up --build -d
# http://localhost:8501 열기

대화형 설치 관리자

Windows용 setup.ps1, Linux/macOS용 install.sh, 또는 AI 코딩 에이전트용 구조화된 온보딩 프롬프트(INSTALL_AGENT.md).

왜 Archon OS인가?

장난감 데모가 아니라 상업적 책임과 GDPR 준수를 위해 만들어졌습니다. 비용 상한, 데이터 유출, 컴플라이언스 경계를 맞춤 접착 코드에 맡기는 프롬프트 체이닝 라이브러리와 달리, Archon OS는 페일 클로즈 로컬 Zero-Egress 라우팅, Atomic BudgetBank 예약, WebAuthn 패스키 승인, EU AI Act / GoBD 문서화, SHA-256 감사 추적을 기본으로 강제합니다 - 3개의 통합 SQLite WAL 데이터베이스(ops.db, business.db, memory.db) 위에서.

자주 묻는 질문

Archon OS란 무엇인가요?

Archon OS는 Hermes Agent 기반의 MIT 라이선스 자체 호스팅 에이전트 운영체제입니다. 8개 도메인에 70개 전문 AI 역할을 편성하며, 실행 전 예산 예약, 로컬 Zero-Egress LLM 라우팅, WebAuthn 패스키 승인, SHA-256 해시 체인 감사 로그를 갖추고 있습니다.

민감한 데이터 유출을 어떻게 막나요?

OmniRoute가 페일 클로즈 Zero-Egress 정책을 적용합니다: 재무, 계약, CRM, 인사, GDPR 워크로드는 인터넷 경로가 없는 내부 Docker 네트워크의 로컬 모델(Ollama 또는 LM Studio)에서만 실행됩니다.

토큰 비용 & 위험한 작업은 어떻게 통제되나요?

중앙 PolicyEngine이 디스패치 전 권한을 검증하고, 권한 있는 도구는 시간 제한 서명 Warrant가 필요하며, BudgetBank가 자금을 원자적으로 예약하고, 고위험 승인에는 WebAuthn 패스키 서명이 필요합니다.

GDPR & EU AI Act에 대응하나요?

네. 민감한 업무 워크로드는 페일 클로즈 Zero-Egress로 서버에 남으며, EU AI Act 위험 등록부, 위변조 탐지 SHA-256 감사 로그, 원클릭 GoBD 절차 문서 내보내기로 뒷받침됩니다.

솔직한 상태

Pre-1.0. 인터페이스와 설정 키는 릴리스마다 바뀝니다. ERP/CRM 모듈은 alpha이며, 다중 사용자 역할 강제는 아직 보강 중이고, 전문가 출력은 의사결정 지원이지 공인된 자문이 아닙니다. 이슈와 PR을 환영합니다.
