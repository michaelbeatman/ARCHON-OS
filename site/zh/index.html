核心功能

AI Boardroom

决策以隔离的多视角辩论形式进行，包含批评者交叉质询与综合归纳，覆盖从 OKR 到 Pre-Mortem 的 55 种框架。

OmniRoute 成本控制

中央交换台将每个请求路由到本地（Ollama、LM Studio）或云端模型。预算在派发前校验，并按模型与任务归集。

Zero-Egress & GDPR

财务、人事、合同与 CRM 数据留在无互联网路由的隔离 Docker 网络内的本地模型上。故障关闭，确保严格的 GDPR 数据驻留。

审计日志、EU AI Act & GoBD

SHA-256 哈希链日志以防篡改方式记录每次派发（供应商、模型、主机），并配有 EU AI Act 风险登记册和一键导出 GoBD 程序文档。

Obsidian 知识库 + RAG

知识库就是你的 Vault。文档与扫描件经 OCR 识别，转换为 Markdown，并在本地索引到 AnythingLLM/Chroma。

带审批闸门的看板

任务需经过四眼闸门：批准、附理由驳回或超时升级。其上还有邮件分拣、CRM 与 ERP 套件（alpha）。

24/7 存活监测 & 自愈

异步事件循环心跳驱动 /livez（停滞时 503）与 Docker 自动重启，并可选配外部「死人开关」Webhook。

加固 & 可追踪

SSRF 与提示注入防护、跨智能体调用的分布式 Trace ID，以及面向大型提示目录的批量 UI 渲染。

Telegram、邮件 & CRM

将收到的邮件与 Telegram 消息分拣为看板任务，同步联系人，并在同一工作区管理报价与合同。

通行密钥 / WebAuthn HITL

高风险审批（付款、预算超支、破坏性操作）需要 Windows Hello、Touch ID 或硬件密钥的加密签名。模型无法伪造审批。

Atomic BudgetBank & 签名 Warrant

令牌与成本预算在执行前以事务方式预留（BEGIN IMMEDIATE）。特权工具需要有时限的 HMAC-SHA256 Warrant。

崩溃安全的 Effect-Ledger

外部副作用由带幂等键的事务账本跟踪，并在未知状态后强制对账，避免重复操作。

安装部署

完整堆栈

六个容器：Archon OS、Hermes Agent、AnythingLLM、Chroma、OmniRoute、Docker socket proxy。

git clone https://github.com/michaelbeatman/ARCHON-OS.git
cd ARCHON-OS
docker compose up -d

零密钥演示

无需 API 密钥与令牌成本的只读展示，适合初次了解。

ARCHON_DEMO_MODE=true \
docker compose -f docker-compose.demo.yml up --build -d
# 打开 http://localhost:8501

交互式安装器

Windows 用 setup.ps1，Linux/macOS 用 install.sh，或为你的 AI 编码智能体准备结构化引导提示（INSTALL_AGENT.md）。

为什么选择 Archon OS？

为商业问责与 GDPR 合规而建，而非玩具演示。 与把成本上限、数据外发和合规边界交给自写胶水代码的提示链库不同，Archon OS 开箱即强制故障关闭的本地 Zero-Egress 路由、Atomic BudgetBank 预留、WebAuthn 通行密钥审批、EU AI Act / GoBD 文档和 SHA-256 审计轨迹 - 运行在 3 个整合的 SQLite WAL 数据库（ops.db、business.db、memory.db）之上。

常见问题

什么是 Archon OS？

Archon OS 是基于 Hermes Agent 的 MIT 许可自托管智能体操作系统。它在 8 大领域组织 70 个专业 AI 角色，具备执行前预算预留、本地 Zero-Egress LLM 路由、WebAuthn 通行密钥审批和 SHA-256 哈希链审计日志。

如何防止敏感数据泄露？

OmniRoute 执行故障关闭的 Zero-Egress 策略：财务、合同、CRM、人事与 GDPR 工作负载仅在无互联网路由的内部 Docker 网络中的本地模型（Ollama 或 LM Studio）上运行。

令牌成本 & 高风险操作如何管控？

中央 PolicyEngine 在派发前校验权限，特权工具需要有时限的签名 Warrant，BudgetBank 原子化预留资金，高风险审批需要 WebAuthn 通行密钥签名。

是否符合 GDPR & EU AI Act？

符合。敏感业务工作负载通过故障关闭的 Zero-Egress 留在你的服务器上，并有 EU AI Act 风险登记册、防篡改 SHA-256 审计日志与一键 GoBD 程序文档导出作为支撑。

坦诚的状态

Pre-1.0。接口与配置键在版本间会变化。ERP/CRM 模块为 alpha，多用户角色强制仍在加固中，专家输出属于决策支持而非持牌咨询。欢迎提交 Issue 与 PR。
